# AngelOS Community Store

[English version](README.md) | Русская версия

Независимый плагин AngelOS для поиска, установки, обновления и удаления
community-плагинов через нативную систему AngelOS.

## Установка

Установщик Python:

```bash
curl -fsSL -o /tmp/install-community-store.py \
  https://raw.githubusercontent.com/futureUnd1ground/angelos-community-store/main/install-community-store.py
python3 /tmp/install-community-store.py
```

Установщик Fish:

```fish
curl -fsSL -o /tmp/install-community-store.fish \
  https://raw.githubusercontent.com/futureUnd1ground/angelos-community-store/main/install-community-store.fish
and fish /tmp/install-community-store.fish
```

Установщик скачивает проверенный release по HTTPS, проверяет архив и manifest,
устанавливает Store в `~/.config/angelos/plugins`, создаёт команду
`community-store`, добавляет `~/.local/bin` в PATH Fish и перезапускает AngelOS.

## TUI

Запуск:

```bash
community-store
```

Стрелки или `j/k` перемещают выбор, `Enter` устанавливает или обновляет,
`d` удаляет, `U` обновляет плагины, `s` обновляет сам Store, `r` обновляет
registry, `/` ищет, `a` показывает все, `i` установленные, `v` обновления,
`q` закрывает интерфейс.

После успешной установки или обновления плагина оболочка AngelOS автоматически
перезапускается, чтобы загрузить его компоненты. При массовом обновлении она
перезапускается один раз после завершения очереди.

## Установка из меню «Выполнить»

Открой поиск приложений (`Mod+Space`), введи `plugins` и часть названия,
автора, описания или тега. Выбери действие `Install`, `Update` или `Remove`.
Удаление использует штатное перемещение плагина в корзину AngelOS.

Страница Store находится в **Настройки → Плагины → Community Store**. После
обновления оболочка перезапускается автоматически, чтобы подхватить компоненты.

## Registry

По умолчанию используется публичный registry:

`https://github.com/futureUnd1ground/angelos-community-registry`

Плагин появляется в Store только после статуса `approved`. Store проверяет
HTTPS, manifest, ID и версию, безопасные пути архива и размер ZIP.

## Публикация

Инструкция разработчика находится в registry:

## Категории для AngelOS

Market 0.8.0 группирует фильтры в «Сюжет и игра», «Оформление», «Плагины и инструменты». Категории учитывают уже существующие возможности AngelOS: рай и ад с кругами, визуальную новеллу, персонажей, сцены и голоса; палитры, скины интерфейса, обои, курсоры, шрифты, значки и эффекты.

| `category` | В магазине |
| --- | --- |
| `Story` | Сюжет |
| `Novels` | Визуальные новеллы |
| `Quests` | Квесты |
| `Characters` | Персонажи |
| `Realms` | Миры и измерения |
| `Dialogue` | Диалоги и сцены |
| `Minigames` | Мини-игры |
| `Voices` | Голоса и озвучка |
| `Pets` | Питомцы |
| `Widgets` | Виджеты |
| `Desktop` | Рабочий стол |
| `Bar` | Панель |
| `Themes` | Оформление |
| `Skins` | Скины интерфейса |
| `Wallpapers` | Обои |
| `Cursors` | Курсоры |
| `Fonts` | Шрифты |
| `Icons` | Значки |
| `Effects` | Эффекты и анимации |
| `AI` | AI-помощники |
| `DeveloperTools` | Разработка |
| `Launcher` | Лаунчер и поиск |
| `Network` | Сеть |
| `Audio` | Музыка и звук |
| `Productivity` | Продуктивность |
| `Integrations` | Интеграции |
| `Accessibility` | Доступность |
| `System` | Система |
| `Utilities` | Утилиты |

В `category` укажи один основной ID из таблицы. В `tags` можно перечислить другие подходящие категории. Названия в реестре остаются стабильными английскими ID, магазин переводит подписи. Прежние категории и теги работают; `Worlds`, `Narrative`, `Lore` и `story-packs` также распознаются. Неизвестная категория автоматически добавляется в список «Плагины и инструменты».

«Сюжет» собирает истории, новеллы, квесты, персонажей, миры, диалоги и голоса. Обычные питомцы и мини-игры не становятся сюжетными без сюжетного тега. «Оформление» объединяет его подкатегории. Поиск понимает русские и английские названия категорий.

Пример сюжетного пакета:

```json
"category": "Story",
"tags": ["story", "novel", "dialogue", "characters", "heaven"]
```

Пример пакета внешнего вида:

```json
"category": "Skins",
"tags": ["skins", "themes", "fonts", "cursor"]
```

Категория описывает содержимое пакета и служит фильтром. Она сама по себе не подключает главы, сцены или голоса к сюжетному движку: автор плагина реализует это через доступные API AngelOS и указывает совместимость и зависимости.

## Установка локального ZIP

В настройках Community Store откройте «Установить из ZIP», перетащите один готовый ZIP-архив на поле и нажмите «Установить ZIP». Можно вставить абсолютный путь к файлу вручную. ID и версия определяются по `manifest.json` в корне архива или в единственной папке плагина. После успешной установки AngelOS перезапустит оболочку, чтобы загрузить компоненты плагина.

Установка работает без сети и использует проверки размера, путей и символических ссылок, блокировку одновременных установок и резервную копию заменяемого плагина. В терминале: `python3 scripts/community-store.py install-local /путь/плагин.zip`.

## Публикация ZIP в Market

В том же поле ZIP нажмите «Опубликовать ZIP в Market». Нужны Git, GitHub CLI и вход через «Войти в GitHub» (`gh auth login --web`); токен не сохраняется в настройках плагина. «Проверить вход» показывает текущий аккаунт. Архив должен содержать описание, версию вида 1.0.0 и существующие файлы объявленных точек входа.

Кнопка создаёт публичный репозиторий `angelos-<id>` в вашем аккаунте (или использует ваш `repository` из manifest), публикует снимок исходников и ZIP как GitHub Release и открывает PR в Community Registry со статусом `pending`, на ветку `main`. Ссылка на заявку появляется в странице. Плагин виден другим пользователям после проверки модератором.

Повторная отправка того же ZIP использует существующий релиз и заявку. Изменённый архив требует новой версии. Уже занятый чужим плагином ID, приватный репозиторий, отсутствующие точки входа и небезопасные архивы отклоняются до публикации. Частично завершённая публикация сохраняется на GitHub для повторной попытки; исходная ветка репозитория не перезаписывается.

Community Search добавляет поиск каталога в «Выполнить…»: `market`, `market dog`, `market publish`. Выбор результата открывает соответствующую карточку магазина, а `market publish` — поле ZIP.
